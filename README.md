## 💡 About
Flask is a **lightweight and easy-to-use Python web framework** for building web applications and APIs.  
It is designed to be **simple, flexible, and easy to extend**, making it ideal for **small to medium projects** and **rapid prototyping**.

---

## ✨ Features
- ✅ Lightweight and flexible web framework  
- ✅ Easy routing and URL handling  
- ✅ Integrated development server  
- ✅ Supports templates (**Jinja2**) and static files  
- ✅ Easy integration with databases and extensions
